# Imagens do Codisseu

## Capturas da alpha — 17/11/2026

As duas capturas atuais foram produzidas com o **Codisseu v0.1.0-alpha.1 core,
Linux amd64**, usando um projeto de demonstração próprio e dados sintéticos.
O usuário autorizou sua publicação em 17/11/2026.

O próprio renderizador nativo do aplicativo gerou os arquivos pelo fluxo
`--capture` / `ctx.request_screenshot`. Ambas têm **1920 × 1200 pixels**, com
`pixels_per_point = 1.5`. Os PNGs foram preservados sem recorte, recompressão
ou edição de pixels e não incluem o painel do sistema operacional.

SHA-256 do executável ELF usado:
`cc28c8f87daf7654a3c8844a3cb75a3286dbe4d431c5819c0506a7ed84e0e9fd`.
