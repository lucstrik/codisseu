# Aparência e temas

Abra **Configurações › Aparência › Tema do aplicativo** para escolher:

- **Codisseu Noturno**: padrão escuro com fundo azulado quase preto, texto claro,
  sintaxe verde/laranja/azul e marcas Git verdes para adições, laranjas para
  modificações e vermelhas para remoções.
- **Codisseu Clássico**: paleta escura anterior.

A escolha muda imediatamente o editor e o restante da IDE: abas, árvore,
painéis, menus, configurações, prévias de código, comparações Git e ferramentas.
O perfil guarda a opção para as próximas aberturas. Sessões antigas sem uma
escolha explícita usam Noturno. Trocar de tema preserva texto, arquivos, seleção,
histórico, layout e escala.

As cores autorais de desenhos e imagens são preservadas. Os controles de
Desenhos com aparência Sistema acompanham a IDE; Claro/Escuro explícitos
continuam disponíveis no desenho. Cores ANSI explícitas do terminal permanecem
associadas ao conteúdo do programa.

Noturno é uma paleta própria inspirada em uma imagem fornecida pelo autor;
não se anuncia correspondência exata com um tema de outro aplicativo.
