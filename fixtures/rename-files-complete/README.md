# Rename independente de arquivo

Fontes próprias PHP/TS sem classes. O rename altera os imports/includes por AST; opções textuais operam sobre basename completo. PHP não inclui notes.txt; TS inclui. O texto de StandaloneTools.php/.ts permanece inalterado, permitindo testar movimento de arquivo com conteúdo dirty e sem edição semântica própria.
