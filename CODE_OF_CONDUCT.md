# Como a gente conversa por aqui

O Codisseu é um projeto aberto para trocar ideias, aprender e construir uma
ferramenta útil. Quem está começando tem o mesmo direito de participar de quem
já conhece o projeto por dentro.

- Trate as pessoas com respeito. Dá para discordar de uma ideia sem atacar quem
  trouxe ela.
- Nas críticas, explique o problema e, quando puder, mostre um exemplo.
- Não publique dados pessoais, credenciais ou informações de outras pessoas.
- Assédio, discriminação, ameaças e ataques pessoais não têm espaço aqui.
- Respeite as decisões de moderação e mantenha as conversas no assunto.

A manutenção pode editar ou remover conteúdo e limitar a participação quando
essas regras forem desrespeitadas. Para pedir ajuda com uma situação, abra uma
issue pedindo um canal privado, sem expor dados de quem está envolvido.
Falhas de segurança devem seguir [SECURITY.md](SECURITY.md).
